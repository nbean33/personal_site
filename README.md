# Noah Bean | Personal Site

Personal website for Noah Bean, Embedded Systems Engineer. Covers experience, technical skills, projects, and writing.

**Live site:** https://nbean33.github.io/personal_site/

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | The whole site: markup, styles, and scripts in one file |
| `404.html` | Page shown by GitHub Pages for missing URLs |
| `noah_bean_resume.pdf` | Resume linked from the "Download Resume" button |
| `favicon.svg`, `favicon.png`, `apple-touch-icon.png` | Browser and home-screen icons |
| `og-image.png` | 1200×630 preview image shown when the link is shared |

## Running locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deploying

Pushing to `main` publishes the site through GitHub Pages.
